# Frequently Used Forms and Contacts

Code

This page provides a quick reference to forms and contacts frequently used for OSC administrative processes.

## Frequently Used Forms

The latest versions of LMU forms can be found in the [LMU Service Portal](https://www.serviceportal.verwaltung.uni-muenchen.de/services/formularcenter/index.html) (SSO required).

The following forms are provided by the **Geschäftsstelle (GS) Psychology** and can be obtained through **Lilia Meier**:

- `Muster Auslagenerstattung 2024`
- `dokumentationsbl-bewirtungen.docx`
- `Reisekostenerstattung_Externe.doc`

| Form | Purpose |
|----|----|
| **Muster 01** | Incoming payments |
| **Muster 30** | One-off payments (German bank account) |
| **Muster Auslagenerstattung 2024** | One-off payments to OSC employees (German bank account) |
| **Muster 35** | Foreign payments |
| **Reisekostenerstattung_Externe.doc** | Form for guest presenters |
| **dokumentationsbl-bewirtungen.docx** | Form to get catering costs back |
| **Muster 70** | Travel authorisation |
| **Muster 71** | Travel reimbursement |
