# Campaigns and Reporting

Code

Campaign links add labels to a URL so Matomo can attribute visits to a campaign or channel. Use the **Campaign URL Builder** in the [OSC Matomo dashboard](https://www.analytics.osc.lmu.de/) to create a link, then share that link in the corresponding email, post, or announcement. Keep labels consistent and do not include personal information in URLs.

Campaign tracking helps us compare the reach and response of outreach efforts. For example, separate links for an email, social media post, or mailing list can show which channels bring more visitors to a tracked OSC page and how those visitors engage with the content. These comparisons help us choose effective communication channels, plan future events, and evaluate whether changes to outreach or webpages improve engagement. The collected results can be aggregated across campaigns; the campaign URL itself should not contain personal information.

Matomo only records campaign visits when the destination page has Matomo tracking installed. Adding campaign parameters to a direct Pretix or formR link does not, by itself, let Matomo count clicks or registrations. For an event without a tracked page, keep the direct registration link if that is best for attendees; use the registration platform’s totals or a short-link service’s click counts instead. For event-planning guidance, see [Advertisement](../osc-events/advertisement.llms.md).

For detailed instructions and the supported parameters, see Matomo’s official documentation:

- [Campaign tracking and URL parameters](https://matomo.org/faq/general/faq_119/)
- [Creating campaign tracking URLs](https://matomo.org/faq/reports/how-to-build-campaign-tracking-urls/)
- [Campaign URL Builder guide](https://matomo.org/docs/tracking-campaigns-url-builder/)
