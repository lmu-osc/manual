# What is a GitHub Organization?

Code

The basics of GitHub organizations, and what you’ll see at github.com/lmu-osc

An organization is effectively a **shared account** that several people belong to. Because the repositories belong to the group, they survive staff changes, and access can be managed in groups rather than person by person. Ours is at [github.com/lmu-osc](https://github.com/lmu-osc).

> **Read the GitHub docs:** [About organizations](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/about-organizations) explains personal accounts versus organizations in full — then come back here for how ours is set up.

## What you’ll see at github.com/lmu-osc

- **Pinned repositories** — a few key repos at the top, such as this manual.
- **Organization README** — a short description of who we are, taken from our `.github` repository.
- **Tabs** — **Repositories**, **Packages**, and **People** are the ones you’ll use. The Repositories tab lists everything we have (public ones to everyone, private ones only if you have access).
